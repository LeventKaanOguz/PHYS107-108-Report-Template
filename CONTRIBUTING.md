## How to Contribute

### Reporting Bugs

If you find a bug, please make sure that it hasn't been reported yet by searching the [issues](https://github.com/leventkaan/METU-PHYS107-108-Report-Template/issues) on GitHub. If you can't find an open issue addressing the problem, please [open a new one](https://github.com/leventkaan/METU-PHYS107-108-Report-Template/issues/new). Make sure to include a **title and clear description**, as much relevant information as possible, and a **code sample** or an **executable test case** demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

If you have an idea for an enhancement, please open an issue with a clear title and description of your suggestion. Explain why this enhancement would be useful and provide as much detail as possible.

### Submitting Pull Requests

1. Fork the repository and create your branch from `main`.
2. Make your changes.
3. Please make sure your code lints.
4. Issue that pull request!

## Style Guides

### Git Commit Messages

- Use the present tense ("Add feature" not "Added feature").
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to 72 characters or less.
- Reference issues and pull requests liberally after the first line.

### LaTeX Style Guide

- Use 2 spaces for indentation.
- Try to keep lines under 120 characters.
- Comment your code where necessary.
